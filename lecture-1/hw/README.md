# ToDo List

Нужно допилить тудулист.

## Что должно уметь приложение

- Добавлять новую задачу
- Удалять задачу
- Отмечать задачу как выполненную
- Искать задачу по тексту
- Фильтровать задачи: все / активные / выполненные
- Показывать количество задач: всего, активных, выполненных
- Удалять все выполненные задачи

## Структура задачи

```js
{
  id: 1,
  text: 'Купить хлеб',
  completed: false
}
```

## Требования

- В input пользователь пишет текст задачи
- По нажатию на кнопку или Enter задача добавляется в список
- Если строка пустая — ничего не добавлять
- После добавления поле ввода очищается
- У каждой задачи должна быть кнопка удаления
- У каждой задачи должен быть checkbox для статуса выполнения
- Выполненная задача должна визуально отличаться: текст перечёркнут
- Поиск должен фильтровать список по подстроке
- Фильтры должны показывать только нужные задачи
- Счётчики должны обновляться после любых изменений

## Дополнительно

Можно сделать:
- красивую верстку
- пустое состояние, если ничего не найдено
- стиль для активного фильтра
- кнопку "Очистить выполненные"

## Bonus: замыкания

Сделай функцию `createTodoItem(todo)` или любую другую, которая возвращает обработчики событий для конкретной задачи.

Задание:
- каждая задача должна иметь свой уникальный обработчик удаления
- обработчик должен “запоминать” id задачи через замыкание
- не использовать глобальный `currentId` в коде, если можно обойтись замыканием

Пример идеи:

```js
function createDeleteHandler(id) {
  return function () {
    deleteTodo(id);
  };
}
```

### Что проверить

- при клике удаляется именно та задача, к которой относится кнопка
- обработчики не мешают друг другу

## Bonus: асинхронность

Добавь небольшую “имитацию загрузки” для добавления или удаления задачи.

Задание:
- при добавлении/удалении задачи показывать состояние "Сохраняем..."
- через `setTimeout` или `Promise` имитировать задержку 300–800 мс
- после задержки обновлять список задач

Пример идеи:

```js
function saveTodo(todo) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(todo);
    }, 500);
  });
}
```

### Что проверить

- пользователь видит, что операция в процессе
- список обновляется только после завершения задержки
- при повторных кликах не ломается логика

## Подсказка

Сделай массив `state.todos` и функцию `renderTodos()`, которая перерисовывает список после каждого изменения.

## Ожидаемый результат

Приложение должно быть рабочим и реагировать на все действия пользователя без перезагрузки страницы.
